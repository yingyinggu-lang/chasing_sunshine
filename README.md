# 追光 2.0 — Android 应用

> 屏幕时间不是罪，它是通往真实阳光的转化资源。

一款把「屏幕时间」交易成「真实阳光」的 Android 健康管理应用。系统用**光线 + 定位 + 步数**三重传感器自动验收每一次户外，把它们结晶成点亮「天空之城」的成长；未完成的屏幕时间会变成「欠自己的阳光债」，用运动和户外来偿还。

---

## 一、快速开始

```bash
# 构建 Debug APK
./gradlew assembleDebug

# 构建 Release APK（已内置签名）
./gradlew assembleRelease

# 安装到已连接的设备
adb install -r app/build/outputs/apk/release/app-release.apk
```

产物路径：

- Debug：`app/build/outputs/apk/debug/app-debug.apk`
- Release：`app/build/outputs/apk/release/app-release.apk`

## 三、核心机制

### 1. 真实阳光验证（三路交叉校验）

```
触发：用户在「进行中」开启某项户外任务
  │
  ├─ 光线传感器 LIGHT：照度 > 阈值（默认 1000 lx）→「晒到光」✓
  ├─ 定位：GPS 坐标判定「在户外」✓
  └─ 步数增量：需步数任务要求 ≥60 步✓
  │
  ▼
至少「光照 + 户外位置」命中 → 记录真实阳光时长并结算
未命中 → 温和提示「这枚币还没晒到太阳哦」，不没收、不惩罚
```

**差异化护城河**：市面上所有屏幕管理/健康打卡 App 验证的是「时间」，本作品验证的是「光」。

降级策略：

- 设备无光线传感器 → 自动降级为「户外定位 + 步数」双路验收
- 拒绝定位权限 → 降级为「光照 + 步数」
- 答辩演示 / 无光感设备 → 设置中开启「手动确认降级模式」按计时结算

### 2. 屏幕债经济

| 时段       | 规则                            |
| -------- | ----------------------------- |
| 周一~周五    | 每 30 分钟屏幕时长 → +1 阳光币（存入账本）    |
| 周六~周日    | 允许「预支」——屏幕时长记为负债（负数）          |
| 还债       | 每 15 分钟真实阳光 → +1 币，**优先冲抵负债** |
| 周日 24:00 | 结算：未清零则提示「你欠了自己 X枚阳光」，不惩罚     |

设计意图：扣分制造羞耻，债务是「自己欠自己的成长约定」。负债曲线可视化，把改进压力转化为游戏化的主动还债。

### 3. 天空之城生态

- **天际线**：每次真户外点亮一座建筑（小屋/高楼/场馆），越排越高越繁华
- **云与天气**：真实天气动画（晴/多云/雨/雪）；雨天解锁「雨中漫步·听雨」双倍卡
- **二十四节气**：内置 24 张节气限定卡，仅当天出现，集齐点亮节气章
- **行为改变报告**：使用前 7 天vs 使用中 7 天双指标折线对比，可直接用于比赛数据答辩

## 五、权限说明

| 权限     | 用途          | 是否必需                 |
| ------ | ----------- | -------------------- |
| 使用情况访问 | 统计屏幕时长      | 必需（未授权则无法统计，不影响其他功能） |
| 定位     | 判断是否在户外     | 可选（拒绝后降级为光照 + 步数）    |
| 身体活动识别 | 步数增量辅助      | 可选                   |
| 通知     | 连续使用提醒、目标达成 | 可选                   |
| 网络     | 天气 API      | 可选（失败时用内置示例数据降级）     |

敏感权限均在引导页「先解释价值、再申请」，定位权限明确标注可降级。

## 六、演示模式

答辩前进入「设置 → 演示模式 → 生成演示数据」，一键生成 14 天模拟数据：

- 14 天屏幕时长与真实阳光记录（前半段屏幕多阳光少，后半段明显改善）
- 期初 20枚阳光币（可直接兑换任务卡）
- 本周 6 枚待还负债（展示还债机制）
- 16 座建筑 + 5 朵云的天际线
- 已解锁徽章与 6 个节气章
- 一周天气数据
- 行为改变报告

演示数据使用固定随机种子，每次生成结果一致，答辩可复现。

## 七、任务卡库

内置 **18 张常规卡 + 24 张节气限定卡**：

- 微运动（6张）：课间伸展、跳绳挑战、眼保健操、深蹲、原地开合跳、靠墙站立
- 户外探索（8 张）：楼下散步、追风跑步、球类运动、晒太阳、阳台远眺、骑行上学、公园探索、天台看云
- 放松（4 张）：听雨漫步、深呼吸、黄昏散步、抬头看太阳
- 节气限定（24 张）：惊蛰·出门听春雷、夏至·正午晒太阳、冬至·正午晒太阳……

每张卡含名称 / 描述 / 所需币 / 难度 / 预计时长 / 验收规则（是否需步数）/ 阳光奖励时长。

## 九、答辩三句话

1. **技术差异化**：别人验证「时间」，我们验证「光」——光线 + 定位 + 步数三重传感器验收真·户外，杜绝假打卡。
2. **机制创新**：把超时屏幕时间建模成「欠自己的阳光债」，用运动还债、负债曲线可视化——不惩罚、不说教，把改进变成游戏。
3. **生态闭环**：屏幕 → 币 → 真户外 → 天空之城成长 → 行为改变数据报告，整套系统可演示、可量化、可直接用于比赛数据答辩。
